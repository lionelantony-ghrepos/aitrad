# Codespaces Path A — smoke standup

Use GitHub Codespaces to try Meridian **as-is** without WSL or laptop Docker. Path A is **local InsForge in Docker** (`npx @insforge/cli local start`) plus the Next.js terminal.

**Quota:** Free Codespaces with spend limit **$0**. A running 4-core space burns 4 core-hours per hour. **Stop the codespace when you are done.**

This is not a PBI. It does not change product policy or tick [docs/04](04-Test-Plan.md).

## Machine size

| First try | If OOM / Docker pull fails / `pnpm seed:all` is killed |
| --------- | ------------------------------------------------------ |
| **4-core / 16 GB** (this `devcontainer.json` `hostRequirements`) | Rebuild on **8-core / 32 GB** |

8-core uses quota twice as fast. Stay on 4-core unless the kernel OOM-killer or InsForge start fails.

## 0. Snapshot fixtures (PR #121)

Offline Yahoo-shaped quotes/bars/news live in `mock_data/market-snapshot/` from [PR #121](https://github.com/lionelantony-ghrepos/aitrad/pull/121) (`cursor/market-snapshot-freeze-d7cd`).

- If that tree is **already on this branch**, `pnpm seed:all` overlays the committed snapshot (no live Yahoo).
- If the folder is **missing** (typical while #121 is still open against `feature`), `pnpm seed:all` still works: GBM universe from `mock_data/*.json`. Login → `/workspace` is enough for this smoke.
- To use snapshot prices before merge: merge or cherry-pick #121 onto this branch, then re-seed. Do **not** run `pnpm market:freeze` on Path A (that hits Yahoo).

## 1. Open a codespace on this branch

1. On GitHub, switch to this branch (the PR branch, or `feature` after merge).
2. **Code → Codespaces → Create codespace on \<branch\>**.
3. Pick **4-core** if the UI asks. Wait until the devcontainer finishes (`post-create` only enables pnpm and checks Docker). If this codespace was created on the old Node 20 image, **rebuild** so it picks up Node 22.
4. Confirm:

```bash
node -v          # v22.x (Codespaces image; not 20.x)
pnpm -v          # 9.15.9
docker compose version
```

Codespaces Path A uses **Node 22** (`mcr.microsoft.com/devcontainers/javascript-node:22-bookworm`) so pnpm can load `node:sqlite` (requires Node ≥22). Repo `package.json` `engines.node` may still say `>=20.11` for local Linux/WSL; do not drop a Codespace back to Node 20.

Docker is **Docker-in-Docker** (nested daemon in the codespace). That is what InsForge Compose needs here; docker-outside-of-docker is not used (no usable host socket, bind-mount path issues).

After pulling this change, **rebuild** the Codespace so the `sshd` feature is installed. Then from your laptop: `gh codespace ssh -c <name>`. SSH is not published publicly; only 3000 and 7130 are forwarded (Private).

## 2. Secrets (never commit `.env`)

Path A keys are **generated by local InsForge**. Do not put them in the repo.

**Optional** GitHub Codespaces secrets (repo or user → Settings → Codespaces → Secrets):

| Name | When |
| ---- | ---- |
| `OPENROUTER_API_KEY` | Only if you exercise live copilot / embeddings. Skip for paper smoke. |

Do **not** set `NEXT_PUBLIC_INSFORGE_URL`, `NEXT_PUBLIC_INSFORGE_ANON_KEY`, `INSFORGE_URL`, or `INSFORGE_API_KEY` as Codespaces secrets. Those must come from this codespace’s `local start` (see `.env.example`). `next.config` already prefers gitignored `.env.local` over ambient `NEXT_PUBLIC_*`.

For this smoke, set `MERIDIAN_EMBEDDING_MODE=hash` so seed does not need a Model Gateway.

## 3. Start InsForge

From the **repo root**:

```bash
npx -y @insforge/cli local start
npx -y @insforge/cli local status
```

First start needs network (~1.5 GB image pull). Default app port **7130** (loopback). If the CLI shifted the port block, use the printed app URL everywhere below.

Keep Postgres / PostgREST / Deno on **localhost**. Do not change port visibility to Public. 5432 / 5430 / 7133 are not published in `.devcontainer/devcontainer.json`; if the Ports panel lists them, leave **Private**.

## 4. Env files (gitignored)

```bash
npx -y @insforge/cli secrets get API_KEY
npx -y @insforge/cli secrets get ANON_KEY
```

Repo-root `.env` (seed / server):

```
INSFORGE_URL=http://localhost:7130
INSFORGE_API_KEY=<API_KEY>
MERIDIAN_EMBEDDING_MODE=hash
```

`local start` writes `.env.local` with `NEXT_PUBLIC_INSFORGE_URL` + `NEXT_PUBLIC_INSFORGE_ANON_KEY`. Copy into `apps/web/.env.local` if Next does not load the repo-root file.

```
NEXT_PUBLIC_INSFORGE_URL=http://localhost:7130
NEXT_PUBLIC_INSFORGE_ANON_KEY=<ANON_KEY>
NEXT_PUBLIC_APP_URL=http://127.0.0.1:3000
```

**Browser vs desktop:** VS Code / Cursor desktop usually forwards 3000 and 7130 as `localhost` — keep the URLs above. If you open Next only via `https://<name>-3000.app.github.dev`, point `NEXT_PUBLIC_INSFORGE_URL` (and `NEXT_PUBLIC_APP_URL`) at the **private** forwarded 7130 / 3000 HTTPS URLs and restart Next. Prefer desktop forwarding if CORS or cookies fail.

Never paste keys into chat, the PR, or committed files.

## 5. Migrate, install, seed

```bash
npx -y @insforge/cli db migrations up --all
pnpm install
pnpm seed:all
```

If migrate was stuck mid-Path A on `0025_audit-chain.sql` (`Changing SQL session configuration is not allowed.`), pull this tip and re-run `npx -y @insforge/cli db migrations up --all`. Failed files are not recorded; the pending 0025 retry plus forward `0028_audit-insforge-compat.sql` (already-applied 0025 hosts) drop the blocked session-config statements.

`pnpm seed:all` is idempotent. If `mock_data/market-snapshot/` is present, it applies that offline snapshot after the GBM universe. Expect demo users from `mock_data/demo-users.json` (docs/06).

If workspace panels error on edge functions after a fresh clone, deploy from [insforge/functions/README.md](../insforge/functions/README.md) (not required just to reach login).

## 8. Stop the codespace

1. Stop Next (`Ctrl+C`) and InsForge: `npx -y @insforge/cli local stop` (keeps volumes) or `local stop --delete-data` to wipe.
2. GitHub → the codespace → **Stop** (or Command Palette → Codespaces: Stop Current Codespace).

Idle timeout still consumes quota until stop. Do not leave an 8-core space running overnight on spend limit $0.

## Caveats

- **Node 22 on Codespaces:** the image is Node 22 even if local engines stay ≥20.11. Node 20.20.x fails pnpm with `node:sqlite`. Rebuild after this bump; do not `nvm use 20` in the codespace.
- **4-core vs 8-core:** InsForge Compose + DinD + `pnpm seed:all` (hundreds of thousands of bars) can OOM on 16 GB. Bump to 8-core, re-run seed, then stop when done.
- **DinD disk:** 4-core machines have 32 GB storage. Image pull + `node_modules` + seed should fit; a full rebuild after failed pulls may need a new codespace.
- **#121:** snapshot overlay is optional for this smoke; merge/cherry-pick if you need frozen Yahoo-shaped quotes.
- **No secrets in git.** `.insforge/`, `.env`, `.env.local` are gitignored.
- Hosted InsForge Cloud is Path B (docs/07), not this checklist.
- **Stuck migrate:** `0025` used function `SET search_path` / session-config helpers the InsForge runner rejects. After pulling this tip, re-run `db migrations up --all` (do not open a new space unless volumes are already wedged).
