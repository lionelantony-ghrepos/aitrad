## Rules

- Decision tables evaluated or seeded: DT-ENT-01 (gate), DT-RISK-01 (editor/simulate/probe in TC-012-01); catalog lists all seeded DT-* keys
- Entitlements / `authorize()`: session `authorize()` plus DT-ENT-01 for `rules:read` / `rules:write` / `rules:simulate` / `rules:publish`

## How to extend

- New table: seed via PBI-011 catalog; it appears grouped by domain automatically
- New input type: add the field name to `inferConditionCellKind` / `enumOptionsForInput` (metadata only — no thresholds)
- Do not put policy numbers in the console; persist cells and evaluate via `rules-service`
- Rebuild the function bundle after engine/admin handler changes: `pnpm functions:bundle:rules-service`
