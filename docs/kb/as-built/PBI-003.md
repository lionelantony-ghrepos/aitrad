## How to extend

- Register a panel in `apps/web/lib/panel-registry.ts` (`PANEL_IDS`, `REGISTRY`, `DEFAULT_LAYOUT_SEQUENCE`) and map the same `component` id in `DockviewReact` `components`
- Replace `PlaceholderPanel` per panel in later PBIs; keep ids stable so stored layouts still deserialize
- Do not persist layout without going through `loadStoredLayout` / `saveStoredLayout` (Zod)
- Replace hardcoded NY session calendar with seeded market calendar in PBI-006; do not copy DT-HRS-01 thresholds into UI
