## Rules

- Decision tables evaluated or seeded: none (retrieval rank is cosine + metadata filters; no DT cutoffs)
- Entitlements / `authorize()`: `news:search` on `search-news` and `searchNewsAction`; `audit_log` on worker (`embed-worker`) and search (`news:search`). `embed-worker` is API-key only.

## How to extend

- Copilot `search_news` should call the same `search-news` function (or `invokeSearchNews`); do not embed `docs/` / `docs/kb/`
- Filings later: new table + worker path, keep `news_embeddings` news-only
- Rebuild `pnpm functions:bundle:embed-worker`, `pnpm functions:bundle:search-news`, `pnpm functions:bundle:news-ticker` after source changes
- Change embedding model only together with a new vector dimension column (do not mix models in `vector(1536)`)
