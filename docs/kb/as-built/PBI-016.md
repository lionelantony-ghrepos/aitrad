## Shipped vs spec

| Item | Status |
| --- | --- |
| Spec intent | done |
| Notes | Trailing stop is a ticket type that persists as `order_type=stop` plus `trail_*` / `high_water_mark` (no new FSM status). Bracket children stay `accepted` until entry fill sets `group_activated` then promotes. OCO is validated and matched (stop-before-limit on the same tick) but has no dedicated ticket tab. Blotter is a group-status list for TC-016-01; virtualized Working/Filled/Explain is PBI-017. DT-VAL-02 buy geometry + trail/OCO/bracket-leg rows were already in the baseline seed; facts (`tp_not_above_entry`, `sl_not_below_entry`, `legs_count`, `trail_*`) are computed in `buildOrderFacts`. Sell-side bracket geometry rows are not in DT-VAL-02. |
