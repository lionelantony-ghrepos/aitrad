## Rules

- Decision tables evaluated or seeded: none published. Opening cash is a local FIRST-match seed in `@meridian/rules-engine` until rules-service exists. DT-SUIT-01 is not computed (tier remains null).
- Entitlements / `authorize()`: authenticated caller required for `provision-account` and `profile-wizard`. Full DT-ENT-01 is PBI-024.

## How to extend

- New auth providers: add a route next to `app/api/auth/oauth/google` using `createAuthActions().signInWithOAuth`
- Do not compute suitability or opening cash in React; call `profileWizardPatch` / `paperAccountSeed` / `executeProvision`
- Keep InsForge SDK out of components — server actions + `lib/api` only
- Deploy `provision-account` and set seed secrets before pointing a live app at InsForge
- Do not enable `E2E_AUTH_STUB` against a real project
