## How to extend

- New policy: add/edit a row in the catalog (`baseline-tables.ts`) or via PBI-012 admin, then `pnpm seed:rules` or publish — do not add thresholds in callers
- New domain: add `ruleDomainSchema` value, `DOMAIN_BINDINGS` row, seed `rule_sets` / `rule_bindings`
- Other functions should POST `rules-service` (or call `evaluateDomain` with ports) — do not fork the evaluator
- Rebuild the function bundle after engine changes: `pnpm functions:bundle:rules-service`
