## Rules

- Decision tables evaluated or seeded: DT-SIM-01 (news sentiment shock row → one-bar drift nudge in `market-tick`)
- Entitlements / `authorize()`: `listNewsAction` requires a session JWT (`getSessionUser` + `getAccessToken`); it uses that token on the records client, not a service role. `news-ticker` is API-key only (`API_KEY` / `INSFORGE_API_KEY`), upserts `news_items` via `createAdminClient`, and writes `audit_log` (`news-ticker`). `publish_news_batch` EXECUTE is `project_admin` only. Migration 0011 grants SELECT to `anon`/`authenticated` and SELECT/INSERT/UPDATE/DELETE to `project_admin` (no INSERT policy for those roles). Browser/client code does not use a service-role key. `market-tick` only **reads** recent `news_items` (`ts`, `symbols`, `sentiment`) to build shocks; it does not write news.

## Residual (non-blocking)

- RLS `news_items_select_public` still allows `anon` SELECT (`USING (true)`). The app JWT-gates reads in `listNewsAction`.
- `DROP POLICY IF EXISTS news_channel_select` matches the `quotes_channel_select` pattern in 0003 (no replacement SELECT policy on `realtime.channels`).
