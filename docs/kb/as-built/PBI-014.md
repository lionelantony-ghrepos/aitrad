## How to extend

- PBI-015 matching-runner should call `assertTransition` / `canTransition` and `release_buying_power` on fills via admin client + `p_user_id` — do not fork a second FSM or reserve path, and do not grant authenticated EXECUTE
- New order types belong in `orderDraftSchema` + DT-VAL rows, not in the ticket
- Session is a fact (`open` / `closed` from NYSE calendar); do not copy hours into application code
- Rebuild `pnpm functions:bundle:order-service` after pipeline changes
