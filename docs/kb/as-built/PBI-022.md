## How to extend

- New typed template: add a kind in `alertKindSchema` + `compileAlertTemplate`; do not put DT-ALRT facts in the UI
- Copilot `create_alert` should call `createAlertRuleAction` / the same condition compiler
- Monitor-runner (PBI-027) should reuse `runAlertCycle` + `evaluateDomain('alerting')`; do not fork throttle math
- Rebuild `pnpm functions:bundle:alert-runner`, `pnpm functions:bundle:market-tick`, `pnpm functions:bundle:news-ticker` after source changes
