## How to extend

- New tables: append `insforge/migrations/0002_….sql`; never edit applied `0001`. Add the id to `LOCAL_MIGRATION_IDS` in `lib/api/migrations.ts`
- When using InsForge CLI, keep `migrations/<timestamp>_….sql` body identical to the numbered source
- New entities: Zod in `@meridian/schemas` first, then a repository module, export from `lib/api/index.ts`
- React components must not call InsForge SDK/REST; only `lib/api`
- Instruments are public-read in 0001; do not add client writes without a later migration + entitlements
