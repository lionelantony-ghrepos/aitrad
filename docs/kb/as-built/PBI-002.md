## How to extend

- New tables: append `insforge/migrations/0002_….sql`; never edit applied `0001`
- Keep CLI `migrations/<timestamp>_….sql` body identical when using InsForge CLI apply
- New entities: Zod in `@meridian/schemas` first, then a repository module under `apps/web/lib/api`, export from `lib/api/index.ts`
- Components must not call InsForge SDK/REST directly
