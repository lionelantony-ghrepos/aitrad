## How to extend

- New action: add a DT-ENT-01 row (draft → publish). Do not add role checks in components.
- New mutating function: call `authorizeEdgeUser` (or `authorize` + `evaluateDomain('entitlements')`) then `audit_log`.
- Copilot write tools (PBI-026) evaluate `ai_action_policy` (DT-AI-01); do not hard-code approval.
- Rebuild bundles after engine changes: `pnpm functions:bundle:rules-service` (and the function you touched).
