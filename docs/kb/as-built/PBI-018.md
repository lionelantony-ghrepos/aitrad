| Spec intent | done |
| Notes | P&L, weights, equity, and buying power (cash minus reserve) are pure functions in `@meridian/schemas` `analytics.ts`. The edge function joins `positions` × `quotes_latest` × `instruments` and does not compute mark math inline. Daily snapshot cron is `POST /functions/analytics-service/snapshot` (service key); it writes only after the NYSE close minute (or `force`) and is idempotent on `account_id + as_of_date`. Live revaluation overlays `useQuotes` on the last `/portfolio` payload. Close is a ticket prefill, not a new opcode. |

## How to extend

- PBI-021 RSI precompute and PBI-028 Portfolio Health should call `assemblePortfolio` / this service — do not fork a second P&L path
- Change mark formulas only in `@meridian/schemas` analytics with fixtures
- Rebuild `pnpm functions:bundle:analytics-service` after service changes
- Subscribe only to `positions:{userId}` for book changes; ticks revalue via `useQuotes`
