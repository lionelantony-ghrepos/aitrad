## How to extend

- New mutating function: call `writeAuditLog` (or `createAuditLogRepository`) after `authorize()`. Add the source path to `MUTATING_AUDIT_SOURCES`.
- Do not UPDATE `audit_log` to “fix” hashes; append only. Retention deletes oldest rows via `apply_audit_retention` only.
- Rebuild `pnpm functions:bundle:audit-service` (and any `*-src` you changed). Apply **0025**.
